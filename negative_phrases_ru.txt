#
# ru_stop v4 stopped a timer and cut off a spoken confirmation because it heard
# «стоп» inside «Поставь таймер через минуту» — a phrase the user says to it
# every day. The «постав-» family was absent from the negatives entirely: the
# list had «Постой», «Простой», «Стало», «Стакан», but nothing built on
# «ставить», and no whole commands at all, only isolated words.
#
# An isolated word is not the same acoustic event as the same word inside a
# sentence, said quickly, with its neighbours running into it. So both are here.
